# Portfolio (Event-Driven Programming Midterm)

Built with HTML, CSS, JavaScript and PHP.

## Run locally
Requires PHP 7.4+ (or XAMPP).
```
php -S localhost:8000
```
Open http://localhost:8000. With XAMPP, put this folder in `htdocs` and open http://localhost/portfolio.

## Events used (js/script.js)
load, click, input, blur, focus, mouseover/mouseout, scroll, keydown, submit (with fetch to contact.php).

## Customize
Edit the `$owner`, `$skills` and `$projects` arrays at the top of `index.php`.
